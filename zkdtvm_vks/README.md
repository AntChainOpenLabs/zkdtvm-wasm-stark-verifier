# Application verification keys

Application VK for zkDTVM proofs on EthProofs. Pass the complete `vk.bin` bytes
as the second input to `verifyCompressedBytes`.

| Version | Application VK | Bytes |
| --- | --- | ---: |
| `v0.8.0` | [v0.8.0/vk.bin](v0.8.0/vk.bin) | 2440 |

The fixed Seal key is embedded in the WASM package.
Verifier ID and checksums: [source.json](../web/samples/source.json).
